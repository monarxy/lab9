# Изменения упрощённой версии текстурирования

Текстурирование приведено к базовому алгоритму из задания. Старое описание расширенной версии больше не применяется.

Изменено:

1. Удалена билинейная фильтрация цветов текстуры. Теперь `sampleTextureNearest()` считывает один ближайший пиксель через `QImage::pixelColor()`.
2. Удалена билинейная параметризация четырёхугольника и её численное восстановление.
3. Каждая грань разбивается на треугольники веером.
4. UV каждого пикселя вычисляются по трём вершинам с помощью барицентрических весов.
5. Удалено чтение и сохранение OBJ `vt`. OBJ сохраняет только геометрию (`v` и `f`).
6. UV автоматически генерируются отдельно для каждой грани в `Polyhedron::calculateNormals()`.
7. Удалён встроенный тестовый рисунок. Текстура поступает из загруженного пользователем `QImage`.
8. Удалён 2x-суперсэмплинг итогового изображения.

Остались загрузка `QImage`, наложение текстуры, два режима освещения, отсечение нелицевых граней, Z-буфер, камера и преобразования объекта.

Подробное объяснение алгоритма находится в `ТЕКСТУРИРОВАНИЕ_ПРОСТАЯ_РЕАЛИЗАЦИЯ.md`.
