# PolyhedraQt — лабораторные работы по 3D-графике

Проект Qt Widgets / C++11 / CMake. Новая работа построена поверх предыдущей лабораторной №8: сохранены модели многогранников, OBJ, генераторы фигур, матрицы аффинных преобразований, камера, отсечение нелицевых граней и Z-буфер. Добавлены освещение, шейдинг Гуро и Фонга, а также наложение текстур.

## Сборка

Требуются CMake 3.16+, компилятор C++11 и Qt 5.12+ с модулем Widgets.

```bash
cmake -S . -B build
cmake --build build
```

Запуск: `./build/PolyhedraQt` (в Windows исполняемый файл будет в каталоге сборки Debug/Release).

## Новая лабораторная: освещение и текстурирование

### Освещение

В группе «Освещение и шейдинг» выбирается метод закраски, задаётся положение точечного источника света по X/Y/Z и цвет материала.

- **Гуро**: нормали вершин получаются усреднением нормалей смежных граней. В каждой вершине вычисляется диффузная составляющая по Ламберту: `I = 0.2 + max(dot(N, L), 0)`. Полученные цвета интерполируются внутри растеризуемых треугольников.
- **Фонг**: нормали интерполируются внутри треугольника, после чего нормализуются. В каждом пикселе вычисляются ambient, diffuse и specular составляющие модели Фонга. Для блика используется отражённый вектор и показатель блеска 32.
- Нелицевые грани по-прежнему могут отсекаться переключателем из лабораторной №8. Для определения лицевой стороны используется внешняя нормаль и вектор от центра грани к камере.
- При аффинном преобразовании нормали граней преобразуются обратной транспонированной матрицей `M^-T`; перенос на нормаль не влияет. После этого нормали нормализуются и используются для получения нормалей вершин.

Растеризатор разбивает многоугольную грань на треугольники. Внутри каждого треугольника используются барицентрические веса; при перспективной проекции атрибуты корректируются с учётом обратной глубины.

### Текстурирование

В группе «Текстурирование» можно сразу включить встроенную шахматную текстуру либо загрузить собственное изображение PNG/JPEG/BMP и включить его наложение. UV-координаты хранятся для каждого угла грани (`Polygon::textureCoordinates`), что позволяет задавать разные координаты на общей геометрической вершине и избегать проблем на швах развёртки. Если OBJ не содержит `vt`, для каждой грани автоматически строится простая плоская UV-развёртка.

При растеризации UV-координаты интерполируются по пикселям, из изображения выбирается цвет текстуры, который умножается на рассчитанный цвет освещения. В OBJ поддерживаются `v`, `vt` и грани `f v/vt` (также допускаются дополнительные поля `/vn`, которые не используются для освещения, поскольку нормали рассчитываются геометрически). Поддерживаются положительные и отрицательные индексы.

## Сохранённые возможности предыдущих лабораторных

- правильные многогранники: тетраэдр, куб, октаэдр, икосаэдр и додекаэдр;
- загрузка и сохранение моделей Wavefront OBJ;
- построение фигуры вращения по образующей вокруг X/Y/Z;
- построение поверхностей `z=f(x,y)`;
- перенос, поворот вокруг координатных осей, масштабирование относительно центра, отражение относительно координатных плоскостей, вращение вокруг центральной и произвольной оси;
- перспективная и параллельная проекции, орбитальная камера, отсечение нелицевых граней и Z-буфер.

## Примечания

- Цвет материала задаётся для отображаемых моделей сцены; дополнительные демонстрационные куб и октаэдр из лабораторной №8 также используют выбранный цвет и источник света.
- UV-развёртка, автоматически созданная для модели без `vt`, является простой плоской развёрткой каждой грани, а не специальной художественной развёрткой.
- Вершинные нормали усредняются по смежным граням. Для моделей с намеренно острыми рёбрами корректнее разделять геометрические вершины по граням (как описано в лекции для клонирования вершин на острых рёбрах).
