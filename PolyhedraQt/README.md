# PolyhedraQt

Учебный проект на C++ и Qt 5 для построения, отображения и преобразования многогранников.

## Основные возможности

- правильные многогранники и модели из OBJ;
- сохранение геометрии в OBJ (вершины `v` и грани `f`);
- построение фигуры вращения и других предусмотренных проектом моделей;
- перспективная и ортографическая проекции, управление камерой;
- отсечение нелицевых граней и Z-буфер;
- два режима освещения: Гуро с диффузной моделью Ламберта и интерполяция нормалей с toon shading;
- перенос, вращение, масштабирование и отражение объекта;
- загрузка изображения текстуры из PNG, JPG, JPEG или BMP через `QImage`.

## Упрощённое текстурирование

UV-координаты автоматически создаются для углов каждой грани простой плоской проекцией. Грани разбиваются на треугольники. Для каждого пикселя вычисляются барицентрические веса, по ним интерполируются UV, после чего из `QImage` берётся ближайший пиксель (`pixelColor`). Цвет текстуры умножается на цвет освещения.

OBJ импортирует и экспортирует только геометрию. Текстурные координаты OBJ (`vt`) намеренно не поддерживаются.

Подробное описание алгоритма, формул и расположения реализации находится в файле [ТЕКСТУРИРОВАНИЕ_ПРОСТАЯ_РЕАЛИЗАЦИЯ.md](ТЕКСТУРИРОВАНИЕ_ПРОСТАЯ_РЕАЛИЗАЦИЯ.md).

## Сборка

Требуются CMake 3.16 или новее, компилятор C++11 и Qt 5 (модуль Widgets).

```bash
cmake -S . -B build
cmake --build build
```
